INSTALL
1. Extract this ZIP.
2. In the exact GitHub Pages folder serving your DriverLink website, replace:
   - index.html
   - css/main.css
   - js/app.js
3. Keep your existing js/firebase.js unchanged.
4. Commit/push the changes and wait for GitHub Pages deployment.
5. Open the website in a private/incognito tab or hard-refresh it.
6. Allow Location permission when you tap Go Online.

TEST
- Tap Go Online: the app should request GPS and save a Saved Pin at the current location.
- A blue dot shows live GPS separately.
- Tap Go Offline: blue dot stops/disappears; Saved Pin remains.
- Drag the Saved Pin marker: it should move and save its new position.
- Tap the Pin Point button, then tap another map location: it should save that point.
- Other signed-in users should see the Saved Pin while this driver is Online.
